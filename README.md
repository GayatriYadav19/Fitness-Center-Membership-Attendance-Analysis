# Fitness Center Membership & Attendance Analysis

## 📌 Project Overview

This project analyzes fitness center membership and attendance data using MySQL. The project focuses on understanding member information, membership plans, attendance records, and trainer details.

## 🎯 Objectives

- Manage fitness center membership data
- Analyze member attendance
- Understand different membership plans
- Analyze trainer information
- Perform data analysis using SQL queries
- Generate useful insights from the data

## 🛠️ Tools & Technologies

- MySQL
- SQL
- MySQL Workbench

## 📂 Database Tables

The project contains the following main tables:

- Members
- Memberships
- Membership Plans
- Attendance
- Trainers

## 🔍 SQL Concepts Used

- SELECT
- WHERE
- ORDER BY
- GROUP BY
- HAVING
- Aggregate Functions
- JOIN
- Subqueries
- Window Functions

## 📊 Analysis Performed

The project includes SQL queries to analyze:

- Member details
- Membership plans
- Membership status
- Attendance records
- Trainer information
- Member-wise attendance
- Membership-wise analysis
- Aggregated fitness center data
